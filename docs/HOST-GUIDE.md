# 主持人指南 — Who Will You Follow? 你會跟隨誰？

呢份指南俾主持人喺開場前睇一次，跟住流程一步一步撳就得。
（管理頁要先用主持人密碼登入；密碼唔會寫喺呢度。）

## 0. 準備

| 裝置 | 網址 | 用途 |
|---|---|---|
| 大電視／投影 | `/tv/` | 俾全場睇：泡泡大戰、身份揭曉進度、領袖卡、計時、投票人數、Round 3 題目 |
| 主持人手機／電腦 | `/admin/` | 控制全場 |
| 玩家手機 | 網站首頁 `/` | 揀角色、玩、睇身份、投票、答題 |

- 管理頁分幾個可摺埋嘅區：**玩家管理**、**玩法說明**、**身份揭曉**、**TV／遊戲**、**Round 3 問答**、**遊戲內容**、**投票結果**。
- 「TV／遊戲」區底部有 **開啟 TV 畫面**，可以直接喺新分頁開 TV。
- TV 只會顯示「人數」之類嘅總數，**唔會**顯示邊個係咩身份、邊個投咗邊個、邊個答咗咩。
- 開場前建議先去 **遊戲內容** 填好 Round 2「神秘描述」＋領袖詞語同 Round 3 五條題目（見第 6 節）。內容會儲喺伺服器，下一場都會保留。

## 1. 等候 — 入場 + 泡泡大戰

1. 玩家用手機開首頁 → 揀角色（每個角色只可以俾一個人揀）。
2. 入咗嘅玩家會出現喺 TV 嘅泡泡大戰；手機按「避開啊／衝過去」就可以喺 TV 上互相撞。
3. 管理頁 **玩家管理** 會見到每個玩家同佢哋係咪在線。如果要踢走某人，可以喺玩家格子度處理。

> TV：泡泡大戰 + 已加入人數　｜　手機：揀角色 → 泡泡大戰按鈕

## 2. 分配身份

喺 **玩家管理**：

- **隨機分配**：自動派身份（預設：真正領袖 1、假領袖 3、真領袖支持者 1、假領袖支持者 2，其餘係平民）。
- 都可以逐個玩家手動揀身份。
- **清除角色**：清走全部身份重新嚟過。
- 假領袖支持者會自動配對一位假領袖（格子上會見到「→角色名」）。

> 身份只有主持人睇到；TV 同其他人手機都唔會顯示。

## 2b. 玩法說明（可選，身份揭曉之前）

1. 喺 **玩法說明** 區撳 **開始玩法說明**。TV 會顯示第 1 頁；泡泡大戰會停。
2. 用 **上一頁／下一頁** 逐頁講解（管理頁顯示「第 N / 7 頁」）：
   玩法說明（約 15 分鐘）→ 遊戲目標 → 角色 → Round 1 聽佢講 → Round 2 誰是真領袖？ → Round 3 破解密碼 → 最終揭曉。
3. 講完撳 **結束**，TV 返回之前嘅畫面。
4. 玩家手機會顯示「請睇 TV 玩法說明」。

- 頁面上嘅數字（最後投票勝利門檻、Round 3 每題門檻同需要成功題數）會跟 **遊戲內容** 嘅設定。
- TV 上嘅領袖卡全部係「？」，唔會顯示邊個係領袖。
- 說明只會講「領袖」同「平民」，**唔會**提及秘密身份，亦唔會講小貼士。
- **身份揭曉之後就唔可以再開玩法說明**（按鈕會停用）。

## 3. 身份揭曉

1. 喺 **身份揭曉** 區撳 **開始身份揭曉**（要撳兩次確認）。
2. TV 會變成「身份揭曉」畫面，顯示「已揭曉 X / N」同進度條（只有數字，唔會顯示邊個睇咗）。
3. 玩家手機會自動跳去身份頁：撳「揭曉我的身份」→ 卡片翻開 → 撳「知道了」。之後都可以撳「再看一次身份」。
4. 管理頁會見到邊個已經睇咗（只有主持人見到）。

## 4. Round 1「三句話」

### 開始
- 喺 **TV／遊戲** 區，全部人揭曉咗之後 **開始 Round 1** 會發光，撳一下就開始。
- 如果有人部手機壞咗未能揭曉：撳一下 **開始 Round 1** 會變「仍然開始」，3 秒內再撳一次就強制開始。
- TV 第一次去 Round 1 會播放領袖卡翻牌動畫（每場只播一次）。

> TV：Round 1 標題 + 四張領袖卡（只顯示角色名）
> 玩家手機：回合頁（說明、領袖、小提示、「等待投票開始」）
> 領袖手機：自己嘅發言指示（真／假領袖版面一樣），同「跟隨你的人數」框

### 發言
1. **TV／遊戲** → 發言一行：撳 **發言 60 秒** 可以輪流切換時間（30／60／90／120 秒／不限）。
2. 撳 **開始發言**。TV 顯示「發言中 · 倒數」，手機顯示「發言中」+ 倒數。
3. 時間到（或撳 **結束發言**）之後手機會顯示「提問時間」。玩家可以向領袖提問。

### 投票
1. 投票一行：揀 **Round 1**，撳 **時限 45 秒** 切換時間（30／45／60／90 秒／無限）。
2. 撳 **開始投票**。玩家手機「前往投票」會亮起，佢哋自己撳入去投（唔會自動跳）。可以「更改投票」直至結束。
3. 領袖唔使投票。
4. TV：「投票中 · 倒數 · 已投票 X / N」。管理頁會即時見到每位領袖嘅跟隨人數（只有主持人見到）。
5. 全部人投完會自動 **封票**（TV 顯示「已封票」）；或者時間到／撳 **結束投票**（撳兩次）。
6. 投票結束後，每位領袖手機會見到自己嘅跟隨人數（只係數字）。

### 私下敲門
- 投票結束後，**真正領袖**手機會出現「私下敲門」按鈕（每輪一次，撳兩次確認）。系統會自己揀投咗假領袖嘅一至兩個人，佢哋手機會收到一張「叩叩……」卡。
- 敲門（紫色部分）同「叩叩」卡**只會喺嗰一輪嘅投票頁**出現；TV 一轉去下一輪（或最終揭曉），就唔會再顯示。每一輪嘅敲門各自獨立。
- 假領袖冇呢個按鈕，但平時版面同真領袖一樣。TV 唔會顯示任何敲門資料；主持人可以喺 **投票結果** 睇紀錄。

## 5. Round 2「誰是真領袖？」

1. **TV／遊戲** → TV 畫面撳 **Round 2**。
2. 平民、真領袖支持者、假領袖支持者 → 手機顯示「神秘描述」卡（內容喺 **遊戲內容** 設定）。
3. 領袖 **睇唔到** 神秘描述，而係見到「你的詞語」卡：只有自己一個詞語，加指示「輪到你時，描述你的詞語，但不可以直接說出來，盡力說服大家你就是真領袖。」
   - 真正領袖 → **真領袖詞語**（完全符合神秘描述）。
   - 每位假領袖 → **自己嗰個假領袖詞語**（按 TV 領袖卡次序：第 1 位假領袖用詞語 1，第 2 位用詞語 2，第 3 位用詞語 3；留空或者多過 3 位 → 用詞語 1）。
   - 真／假領袖畫面完全一樣（同一個版面、同一句小提示），睇唔出真假。
   - 每部手機只會收到自己嗰一份：領袖只收到自己個詞語，平民收唔到任何詞語；TV **唔會**顯示任何描述或詞語。
   - 領袖手機一樣會見到「跟隨你的人數」。
4. 發言、投票、封票、私下敲門嘅做法同 Round 1 一樣，投票嗰行記得揀 **Round 2**。

> TV：Round 2 標題 + 領袖卡 + 發言／投票計時　｜　手機：平民 → 神秘描述；領袖 → 你的詞語　＋ 前往投票

## 6. 遊戲內容（建議開場前填好）

**遊戲內容** 區：

- **Round 2「誰是真領袖？」**：
  - **神秘描述（平民）**（必填，最多 400 字）：平民、真領袖支持者、假領袖支持者見到；領袖睇唔到。
  - **真領袖詞語**（必填，最多 20 字）：真正領袖見到，要完全符合神秘描述。
  - **假領袖詞語 1／2／3**（詞語 1 必填，最多 20 字）：每位假領袖見到自己嗰個，要大致符合神秘描述。派咗身份之後，欄位會顯示邊個角色攞邊個詞語；未派身份就按次序（第 1、2、3 位假領袖）。詞語 2／3 留空 = 用詞語 1。
  - 仲係預設內容嘅欄位會有「例子」標記，記得改成你自己嘅題目。
- **每題門檻**：每題至少幾多 % 玩家答對先算成功（預設 60%）。
- **成功 X 題解鎖**：成功幾多題就解鎖最後線索（預設 3 題）。
- **最後的線索**：解鎖後喺 TV 同手機顯示。
- **第 1–5 題**：題目 + A–D 四個選項，撳選項旁邊嘅圓點揀正確答案。
- **結局：勝利門檻**：最後投票有幾多 % 投票者跟隨真正領袖就算勝利（預設 70%，1–100）。
- 撳 **儲存內容**（有改動時會顯示「儲存內容 *」）；**還原** = 放棄未儲存嘅改動。

> 第 2–5 題而家係「（範例）」題目，請換成真題目。
> 已經開咗嘅題目唔會因為改內容而改變（開題嗰刻已經固定）。

## 7. Round 3「破解密碼」

### 開始
1. **TV／遊戲** → TV 畫面撳 **Round 3**。
2. 手機顯示說明（門檻、成功題數）、「解鎖進度」五個圓圈，同「等待第 1 題」。

### 每一題（**Round 3 問答** 區）
1. 上面五格顯示每題狀態（未開始／作答中／成功／未達標）；喺「題目」一行揀要開邊題。
2. 撳 **作答 不限時** 切換時間（不限時／20／30／45／60／90 秒）。
3. 撳 **開始第 N 題**。
   - 玩家手機：題目 + A–D 選項，撳一個就作答，結束前可以改答案。**所有非領袖都必須作答**：未作答嘅手機會有閃動嘅「請作答」提示，直至作答為止。
   - 領袖手機：睇到題目，但唔可以作答。
   - TV：題目、四個選項、倒數、「已作答 X / N」（**唔會**顯示答案或答對率）。
   - 管理頁：即時見到 已作答、答對人數、答對 %，同 **未作答 N 人（名字）**（只有主持人見到，方便你提醒佢哋）。
4. **全部人作答咗就會自動結束**（管理頁顯示「全部已作答，自動結束」）。
   - 計時係可選：揀咗秒數嘅話，夠鐘都會自動結束。
   - 如果有人一直唔答（例如手機冇電），可以撳 **結束作答** 強制結束：要撳兩次，第一次會提示「X 人未作答」。
   - TV 同手機會顯示正確答案、「成功！」或「未達標」同答對 %；解鎖進度圓圈會更新。
5. 再揀下一題，重複。
   - 答對 % 係用「所有非領袖玩家」計（冇作答都當答錯）。
   - 重新開一條已經答過嘅題目會清除嗰題結果（管理頁會先問你確認）。
   - **重設問答進度**（撳兩次）會清除全部題目結果。
6. 成功夠題數之後，TV 同手機會顯示「最後的線索 已解鎖！」同線索內容。

### 最後投票
- **TV／遊戲** → 投票一行揀 **最後投票** → **開始投票**。投票期間 TV 會暫時收埋問答畫面，顯示投票倒數同人數；結束後問答／線索畫面會返嚟。

## 8. 最終揭曉

最後投票結束之後：

1. 管理頁 **最終揭曉** 區 → 撳 **進入最終揭曉**。
   - TV：「最終揭曉」+ 所有領袖卡（角色圖 + 名字），身份用「?」遮住。
   - 手機：「請看 TV！」，下面列出已經翻開嘅結果（未翻開嘅顯示「未翻開」）。
2. （可選）撳 **顯示最後投票結果**：每張卡下面顯示最後投票嘅跟隨人數（最後投票未結束嘅話 TV 唔會顯示票數）。再撳一次收返。
3. 管理頁每位領袖一格（名字、身份、支持者，只有你見到），**任何次序** 都得：
   - 撳 **翻卡** → TV 翻開嗰張卡：
     - 假領袖 → 蓋上「假領袖」印章。
     - 真正領袖 → 「真正領袖」印章 + 皇冠 + 發光 + 彩紙。
   - 翻開之後，有支持者嘅領袖可以撳 **揭曉支持者** → 支持者角色從卡旁邊彈出嚟（只有角色圖同名字，唔會寫身份）。冇支持者嘅會顯示灰色 **沒有支持者**（撳唔到）。
   - 建議玩法：先翻冇支持者嘅假領袖，再翻有支持者嘅假領袖（揭曉支持者），最後先翻真正領袖。揀錯咗都冇問題，照翻其他卡就得。
4. **全部翻開**（撳兩次）：未翻開嘅卡逐張翻開（只翻卡，支持者要另外揭曉）。
5. **重設揭曉**（撳兩次）：所有卡蓋返，可以重新揭曉。
6. 如果 TV 嘅系統設定咗「減少動態效果」，會用簡單淡入代替動畫。新一場會自動清除揭曉進度。

> TV 同手機只會顯示已經翻開嘅資料；未翻開嘅卡唔會洩漏身份。

## 8b. 結局

最後投票結束之後（通常翻晒卡之後）：

1. 管理頁 **最終揭曉** 區最底 **結局**：會先顯示預覽（只有你見到）：「X / N 人（約 P%）跟隨真正領袖 → 勝利／假領袖勝出（門檻 70%）」。
2. 撳 **顯示結局** → TV 同所有手機轉去結局畫面。
   - 如果真正領袖張卡仲未翻開，要撳兩次（第一次會顯示「真正領袖未翻開，再按一次」）。
   - 最後投票未結束嘅話，掣係灰色（撳唔到）。
3. TV **逐張點票**（次序隨機，但同一場固定）：每一票令該領袖嘅「N 票」跳一下；投真正領袖嘅票，進度條同「X / N 人」就升一格。快到目標 70% 之前會停一停（虛線會閃）。20 個投票者大約 12 秒點完，點完先顯示結果：
   - **勝利！**「大家成功跟隨了真正的領袖！」：真正領袖戴皇冠喺中間，小羊行出嚟，彩紙。
   - **差一點點…**「假領袖勝出…」：假領袖得意咁跳，真正領袖好失落。
   - 下面列出每位領袖（只係角色名）同最後投票票數；唔會顯示投票者名字。
4. 手機：TV 點票期間顯示「點票中… 請看 TV，正在點票…」（手機收唔到任何結果）；TV 點完約 1.5 秒後先顯示同一個結果 + 自己嘅一句：「你跟隨了真正的領袖 🎉」或「你跟隨了 <名字>」；領袖會見到自己嗰邊嘅結果同跟隨人數；最後「多謝參與幸福小組！」。
5. **返回揭曉**：TV 同手機返去最終揭曉畫面（可以再撳 **顯示結局**，會重新點票一次）。TV 中途重新載入會由而家嘅進度繼續；點完之後重新載入會直接顯示結果。
6. 門檻喺 **遊戲內容** → **結局：勝利門檻** 改；文字喺 `data/texts.json` → `ending` 改。減少動態效果嘅 TV 會直接顯示結果（手機仍然等點票時間完先顯示）。

## 9. 未有嘅部分

- 個人計分仲未做。
- Round 1–3 嘅領袖指示（暫時係草稿文字，未可以喺管理頁修改）；第 2–5 題係「（範例）」題目。

## 10. 新一場

- **玩家管理** → **新一場**：封存今場記錄，清空玩家，重新開始。遊戲內容（神秘描述、題目、結局門檻）會保留；最終揭曉進度同結局會清除。
- **TV／遊戲** → **回到等候**：TV 返去泡泡大戰（要確認）。
